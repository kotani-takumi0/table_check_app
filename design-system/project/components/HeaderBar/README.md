# HeaderBar

高さ40pxの一列で、店タイマー・同期状態・バージョン・時刻・全卓消去をこの順に置きます。スマホでは34pxに縮みます。

左から詰め、バージョンに `margin-left: auto` を掛けて右の3つを右端に寄せます。同期状態が出るときだけ、それが `auto` を引き受けます。幅419px未満ではバージョンを消し、時刻とタイマーを優先します。

全卓消去は一番よく押す店タイマーから最も遠い右端に置き、押しても確認ダイアログが出るだけです。文字色は全体が `muted`。ヘッダーは常に見えているので、目立たせると卓の状態より先に目が行ってしまいます。

**使う側が用意するもの**: 現在時刻、同期状態、店タイマーの完了時刻、消去できるかどうか、2つのハンドラ。アイコンは絵文字の仮置きで、差し替え予定です。
