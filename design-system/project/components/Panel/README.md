# Panel

卓を長押しすると開く詳細パネルで、カードに載せきれない操作を全部ここに集めます。

幅は `min(440px, 100%)`、角丸10px、背景は `surface`。背後は黒40%で覆い、`overscroll-behavior: contain` で後ろのフロア図を動かしません。高さは `100dvh - 32px` までで、超えたら中だけスクロールします。

中身は3段です。見出し（卓番・状態名22px・経過時間）、時刻の打ち直し（56px幅のラベル・入力・「いま」ボタン）、操作の並び。操作は折り返して等幅に伸びます。

時刻の入力は `bg` の面に `mono` 18px。エラーは行いっぱいに `danger` で出します。

**使う側が用意するもの**: セッション、現在時刻、各操作のハンドラ、閉じる手段。開いたらパネルにフォーカスを移し、背後を `inert` にします。
