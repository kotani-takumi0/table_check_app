# FloorGrid

店の見取り図をそのまま画面にした15列×7行のグリッドで、卓カードと間仕切り線を置く土台です。

卓の位置は画面の都合ではなく実際の店の配置で、`col` `row` `colSpan` `rowSpan` を席ごとに手で持っています。だから卓カードは「何列目か」を自分で知らず、割り当てられたマス目の縦横比だけで姿（標準・compact・narrow）を決めます。

隙間は方向で変えます。横向きは行12px・列6px、縦向きは行6px、スマホは4px。行間を広く取るのは卓カードが横長で、上下の境目のほうが見失いやすいからです。

間仕切り線とカウンターの文字は `z-index: -1` でカードの下に敷きます。線は `line` の1px、グリッドの隙間の中央に来るよう負のマージンで寄せています。

縦向きでは配置ごと時計回りに90度回し、7列×15行になります。線も同じ規則で回します。

**使う側が用意するもの**: 席の一覧（id・種別・位置）、いま在席のセッション、通知の配列。グリッドの列数と行数は席の一覧から決まります。
