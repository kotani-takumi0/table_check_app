# Toast

閉じるまで残る通知で、フロア図の2行目の空きマスに置きます。行の高さは変えません。

面・枠・文字を `--tone-bg` `--tone-line` `--tone-text` の組で持ちます。既定（danger）はいま対応の `now-bg` `now-line` `now-text`、`warning` はもうすぐの `soon-bg` `soon-line` `soon-text`。警告の卓カードと同じ組なので、フロア図の中に置いても異物になりません。

入る行数を超えたら、先頭1件だけを出して残りをまとめます。1行しか入らない画面では、まとめを先頭の通知の中に「ほか N件」として入れます。先頭を片付けると次が繰り上がります。

操作は最大2つ。左が対応（「L.O.確認済みにする」）で操作の `action` の塗りに `on-action` の文字、右が「閉じる」で `line` の枠。対応ボタンは通知の文言と同じ動詞を使ってください。

**使う側が用意するもの**: 通知の配列（キー・文言・トーン・任意の操作）、閉じるハンドラ、入る行数（1か2）。
