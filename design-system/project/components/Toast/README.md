# Toast

閉じるまで残る通知で、フロア図の2行目の空きマスに置きます。行の高さは変えません。

`--tone` に `warning` か `danger` を入れ、枠45%・面12%・文字は `tone` そのままで作ります。卓カードと同じ比率なので、フロア図の中に置いても異物になりません。

入る行数を超えたら、先頭1件だけを出して残りをまとめます。1行しか入らない画面では、まとめを先頭の通知の中に「ほか N件」として入れます。先頭を片付けると次が繰り上がります。

操作は最大2つ。左が対応（「L.O.確認済みにする」）で `tone` の枠、右が「閉じる」で `line` の枠。対応ボタンは通知の文言と同じ動詞を使ってください。

**使う側が用意するもの**: 通知の配列（キー・文言・トーン・任意の操作）、閉じるハンドラ、入る行数（1か2）。
