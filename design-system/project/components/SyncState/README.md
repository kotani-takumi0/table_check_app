# SyncState

書き込みがサーバーに届いているかを出す1行で、同期できているときは何も描きません。

送信待ちは `warning`、オフラインは `danger`。オフラインの文言は状態の説明ではなく次の行動（「声かけに戻ってください」）にしています。端末が繋がらない間は、画面ではなく人づてで伝えるしかないからです。

12pxで `margin-left: auto`。出ている間はバージョンから右寄せの役を引き取ります。スマホでは省略記号で切ります。

**使う側が用意するもの**: 同期状態と、これを出してよい画面かどうか。`role="status"` を付け、割り込まずに読み上げさせます。
