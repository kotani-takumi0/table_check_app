# TablePick

卓の移動・追加・団体のための部品で、卓チップ、選択中のバー、選べる空席の3つからなります。

卓チップは高さ36pxのピルで、外せるものだけ右に32pxの×を持ちます。外せないチップは右の余白を12pxに戻し、×の場所を空けたままにしません。

選択中はフロア図の上に高さ40pxのバーを出します。`seated` の1.5px枠に14%の面。フロア図そのものが選択肢になっている状態なので、バーは「何を選んでいるか」だけを言います。

選べる空席は `seated` の2px破線に6%の面。選べない在席カードは不透明度0.35に落とし、`inert` で押せなくします。消さずに薄くするのは、どこが埋まっているかを見ながら選ぶためです。

卓番は必ず数値順に並べ替えます。どの端末でも同じ並びに見せるためです。
