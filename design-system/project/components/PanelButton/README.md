# PanelButton

パネルとダイアログのボタンで、既定・primary・danger の3種と無効の状態を持ちます。

既定は `line` の枠に `bg` の面。primary は `seated` の枠に12%の面で、その場面で普通に選ぶ道を示します。danger は `danger` の枠・面・文字に太字で、消去や巻き戻しに使います。無効は不透明度0.4にして、消さずに残します。押せないことより、そこに何があるかを見せるほうが大事だからです。

高さは50px。カード内の `next-button` も同じ50pxですが、枠と面は `--st` から作るので、その卓の状態色をまといます。パネルの primary が常に `seated` の青なのと対照的です。

並びは `flex: 1` で等幅に伸び、入らなければ折り返します。1行に3つまで。
