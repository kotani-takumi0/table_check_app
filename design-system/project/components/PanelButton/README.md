# PanelButton

パネルとダイアログのボタンで、既定・primary・danger の3種と無効の状態を持ちます。

既定は `line` の枠に `bg` の面。primary は茎の緑 `action` の塗りに `on-action`（白）の文字で、その場面で普通に選ぶ道を示します。danger はいま対応の `now` の枠・`now-bg` の面・`now-text` の文字に太字で、消去や巻き戻しに使います。無効は不透明度0.4にして、消さずに残します。押せないことより、そこに何があるかを見せるほうが大事だからです。

高さは50px。カード内の `next-button` も同じ50pxで、`surface` の面に `line-strong` の枠。警告の卓の淡い地の上でも、ふだんの卓の上でも同じ見た目です。

並びは `flex: 1` で等幅に伸び、入らなければ折り返します。1行に3つまで。
