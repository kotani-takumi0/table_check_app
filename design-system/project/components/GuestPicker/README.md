# GuestPicker

ご案内のときに人数を聞く画面で、1〜8は数字ボタン、9名以上はステッパーで入れます。

数字ボタンは4列×2行、高さ56px。この系で一番大きい押しどころです。来店直後の一番慌ただしい瞬間に、見ずに押せる大きさを優先しました。文字は22px太字。

9名以上はステッパーで増減し、決定ボタンで確定します。団体は全員の合計を1つの数として持ち、同じセッションのどの卓にも同じ人数を出します。

「あとで」で人数なしのまま進めます。人数は未入力を許す値で、カード上は `?名` と `muted` で出ます。入力を強制すると、忙しいときにご案内そのものが遅れるからです。

**使う側が用意するもの**: 卓番、確定のハンドラ、見送りのハンドラ。上限は99です。
