# PayToggle

お会計が済んだかどうかだけを持つトグルで、卓の状態（ご案内済み〜退店済み）とは独立して切り替わります。

未払いは破線の枠に `muted` の文字。会計済みは `text` で塗りつぶした実線のピルにします。破線と実線の差を付けているのは、色が読めない状況でも「まだ／済んだ」が形で分かるようにするためです。

幅で3段に縮みます。余裕があれば「未払い／会計済み」、狭い卓では「¥／¥✓」、スマホでは卓番の横に10pxの `¥✓` を添えるだけでボタンにはしません。スマホで押す操作は詳細パネルに集めます。

**使う側が用意するもの**: 会計済みの時刻（null なら未払い）と、切り替えのハンドラ。`aria-pressed` を必ず付け、ラベルには押した結果（「押すと未払いに戻す」）を書きます。
