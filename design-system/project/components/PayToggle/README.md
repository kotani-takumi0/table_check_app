# PayToggle

お会計が済んだかどうかだけを持つトグルで、卓の状態（ご案内済み〜退店済み）とは独立して切り替わります。

卓カードの上のトグルはなくし、切り替えは詳細パネルの上の方（段階を進めるボタンの下）の「お会計」の行で行います。カードは表示だけで、大きい卓は右上に「会計済」、低い卓・細い卓・カウンターは「¥✓」、スマホは卓番の横に10pxの `¥✓` を添えます。未払いのときは何も出しません。

**使う側が用意するもの**: 会計済みの時刻（null なら未払い）と、詳細パネルの切り替えのハンドラ。ボタンのラベルには押した結果（「お会計済みにする」「未払いに戻す」）を書きます。
