# SeatCardDensity

同じ卓カードが取る4つの姿を並べたページで、新しい要素をカードに足すときの判断材料です。

標準は高さ2行のテーブル卓。compact は高さ1行で、卓番を左上へ絶対配置に逃がします。narrow は縦向きの細い卓で、状態を1行いっぱいに。mini はスマホで、卓番・状態・タイマーだけを中央に縦積みし、ボタンを載せません。

mini の文字は `min(12px, 25cqw)` とカード幅で決まります。1列ぶんのカードは幅48px前後しかなく、タイマーは最大7文字入ります。テーブル卓だけ上限を14pxに上げます。

新しい要素を足すときは、標準だけでなく4つ全部で置き場所を決めてください。置けない姿があるなら、小さくするのではなく、その姿から外して詳細パネルへ送ります。10px未満の文字と32px未満のタップ領域は作りません。
