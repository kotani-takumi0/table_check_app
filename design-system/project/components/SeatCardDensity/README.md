# SeatCardDensity

同じ卓カードが取る姿を並べたページで、新しい要素をカードに足すときの判断材料です。

大きい卓（`.table.full`）は真ん中に文字盤と四隅の情報。低い卓（`.table.low`、上段の高さ1行）は左に卓番・段階・残り時間、右に小さめの文字盤。細い卓（`.table.low.narrow`、縦向きの幅1列）は上に情報、下に文字盤。カウンター（`.counter`）は円の文字盤。mini はスマホで、文字盤を出さず卓番・段階・時:分だけを中央に縦積みし、警告は淡い地の色だけで伝えます。文字盤の大きさはカードの小さい辺に合わせます（`container-type: size` の `cqw` `cqh`）。

mini の文字は `min(12px, 25cqw)` とカード幅で決まります。1列ぶんのカードは幅48px前後しかなく、タイマーは最大5文字（`1:58`）入ります。テーブル卓だけ上限を14pxに上げます。

新しい要素を足すときは、標準だけでなくどの姿でも置き場所を決めてください。置けない姿があるなら、小さくするのではなく、その姿から外して詳細パネルへ送ります。10px未満の文字と32px未満のタップ領域は作りません。
