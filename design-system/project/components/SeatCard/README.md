# SeatCard

1卓の状態と経過時間を示すカードで、フロア図の主役です。

状態ごとの色はありません。ふだんの卓は `surface` の面に `line` の枠、状態名は `text` の無彩色で、段階は文字で伝えます（退店済みだけ `exited` クラスで `muted` に薄くする）。色が付くのは警告のときだけで、L.O.（もうすぐ）は `alert-soon` で琥珀の `soon-bg`・`soon-line`・`soon-text`、お通し未提供・お席の時間（いま対応）は `alert-now` で朱の `now-bg`・`now-line`・`now-text` になります。状態名・理由・長押し中の輪郭は `--st` を通して同じ文字色をまといます。

在席カードは `占有` と `空席` で骨格が違います。空席は透明な面に `line` の枠だけで、卓番を20pxに上げます。空いている卓ほど遠くから探されるからです。

操作は3つ。押すと次の状態へ進み、長押し600msで詳細パネルが開き、右上の会計トグルは状態と独立して切り替わります。退店済みの卓を押すと、表示が消えるのを待たずに次のご案内に入れます。

**使う側が用意するもの**: 席、セッション、現在時刻、4つのハンドラ（ご案内・次へ・開く・会計）、`mini` と `picking` の真偽値。時間の判定とラベルはカードの外で決めます。

読み上げ用のラベルには、短縮していない状態名と人数と警告の理由をすべて入れてください。見た目が短縮されていても、耳から入る情報は削りません。
