# SeatCard

1卓の経過時間と段階を示すカードで、フロア図の主役です。主役はアイコンの茎の時計をなぞった文字盤です。

文字盤は塗った丸（`dial-face`）の中に経過（時:分、1分ごとに動く）、縁に12個の点（`dial-dot`、10分ごと）、90〜120分に淡い琥珀の帯（`dial-band`、L.O.から退席まで）。12時から時計回りに経過の弧が伸び、120分で一周します。弧が帯に入れば数字を読まなくても分かります。

大きい卓は四隅に情報を置きます。左上に卓番（団体は「+14」）、右上に人数とコース（料理の進み 3/8）・会計済、左下に段階（警告なら理由の札）、右下に「L.O.まで55分」「退席まで29分」。低い卓は左に卓番・段階・残り時間、右に小さめの文字盤。カウンターは円の文字盤で、卓番は円の上、段階は円の下です。

状態ごとの色はありません。ふだんの卓は `surface` の面に `text` の弧と段階名。L.O.（もうすぐ）は `alert-soon` で琥珀の地・丸・弧と `soon` の札、お通し未提供・お席の時間（いま対応）は `alert-now` で朱の地・丸・弧と `now` の札になります。退店済みはカードごと薄くし、右下に「押すとご案内」。コースの開始待ちは文字盤の中を「開始前」にします。

空席は点線の枠（テーブルは角丸の四角、カウンターは円）。空いている卓ほど遠くから探されるので、卓番を大きめに出します。

操作は2つ。テーブルは押すと詳細パネル（退店済みは次のご案内）、カウンターは押すと次の段階へ進みます。どちらも長押し600msで詳細パネル。「次へ」と会計はカードに載せず、詳細パネルの一番上に置きます。

**使う側が用意するもの**: 席、セッション、現在時刻、3つのハンドラ（ご案内・次へ・開く）、`mini` と `picking` の真偽値。時間の判定とラベルはカードの外で決めます。

読み上げ用のラベルには、短縮していない状態名と人数と警告の理由をすべて入れてください。見た目が短縮されていても、耳から入る情報は削りません。
