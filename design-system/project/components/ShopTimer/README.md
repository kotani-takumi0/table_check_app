# ShopTimer

卓とは別に、店全体で周期的にやる作業（トイレチェック30分、トイレ清掃120分）の残り時間を出すピルです。

幅がないのでヘッダーにはアイコンと残り時間だけを出し、作業名は読み上げと詳細パネルで使います。期限を過ぎると `danger` の枠と12%の面に変わり、文字を「時間です」に替えます。色と語の両方を変えるのは、`danger` が薄いテーマでも気付けるようにするためです。

一度も済にしていなければ、期限は0として扱い、最初から「時間です」を出します。残り時間は周期でクランプします。済にした直後に周期を超えた数字が見えるのを防ぐためです。

押しても済にはならず、詳細が開くだけです。ヘッダーの狭い場所で誤って押しても取り返しがつくようにしています。

**使う側が用意するもの**: タイマーの定義（id・名前・アイコン・周期）、最後に済にした時刻、現在時刻、開くハンドラ。
