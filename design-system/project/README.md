# 卓タイマー デザインシステム

居酒屋のフロアで、片手にお盆を持った人が、歩きながら一瞥で読むための系です。
アプリ `table-check-app` の `src/App.css` と React コンポーネントから、実際に使われている値だけを起こしました。

## この系が守っていること

**状態は色そのもの。** 卓カードは状態ごとの色を `--st` という1つの変数に受け取り、文字色・枠・12%の下地・長押し中の輪郭を全部そこから作ります。カードに状態ごとのクラスはありません。色を1つ差し替えれば、その状態の見え方がまとめて変わります。

**警告は状態色を上書きする。** 通常は `seated` `otoshi` `lo_done` `exited` の4色（コースの卓は `seated` `otoshi` の代わりに `course_wait` `first_drink`）。時間を過ぎると `--st` が `warning` か `danger` に差し替わり、状態名も理由の語も同時に警告色になります。これは「状態を忘れさせて、対応を思い出させる」ための上書きです。

**色だけでは伝えない。** 警告には必ず「お席の時間」「お通し未提供」のような語が付きます。後述のとおり `warning` と `otoshi` は明度差が足りないので、語は飾りではなく本体です。

**影はない。** 面の区別は 1px と 1.5px の枠と、12%の色の下地だけで付けます。`shadow` のトークンはこの系には存在しません。

**数字は等幅。** 時刻と経過時間は Roboto Mono の `tabular-nums`。1秒ごとに桁幅が動くと、視界の端で気が散るためです。

**押せるものは指で押せる。** 主要な操作は50px、下限は32px。スマホでは卓カード自体を押して詳細パネルを開き、カードの上に小さなボタンを載せません。

## 色

13色。`bg` `surface` `text` `muted` `line` の5つだけがテーマで入れ替わり、状態と警告の8色はライトとダークで同じ値です。

コースの卓は、通常の「ご案内済み」「お通し提供済み」の位置に「開始待ち」（`course_wait`）と「ファーストドリンク提供済み」（`first_drink`）が入ります。状態の値は通常と同じで、色と名前だけを差し替えます。地の明度が変わるぶん、同じ状態色でもダークのほうが浮いて見えます。

`color-mix(in srgb, var(--st) 12%, var(--surface))` が下地、`45%` が枠、`8%` がカード内ボタンの面。この3つの比率で面の階層を作っているので、新しい面を足すときもこの3段から選んでください。

### コントラストの実測

状態色は下地（12%混色）の上に置かれます。22px太字＝大きな文字なので 3:1 が基準ですが、下回る組み合わせが残っています。

| 状態色 | ライトの下地で | ダークの下地で |
| --- | --- | --- |
| seated | 3.55 | 3.10 |
| otoshi | 2.96 | 3.67 |
| lo_done | 4.49 | 2.48 |
| exited | 2.35 | 4.61 |
| warning | 2.40 | 4.53 |
| danger | 4.02 | 2.79 |
| course_wait | 3.55 | 3.12 |
| first_drink | 3.48 | 3.21 |

ライトの `otoshi` `exited` `warning`、ダークの `lo_done` `danger` は 3:1 に届きません。元のコードの値をそのまま残してあります。あとから足した `course_wait` `first_drink` は、両テーマで 3:1 を超える値を選びました。直すなら、状態色のダークテーマ側を別値に分けるのが順路です。`alert-reason` は14px太字なので本来4.5:1が要りますが、どのテーマでも満たしていません。ここは語の意味で補っています。

`text` は地の上で12〜15:1、`muted` はライトで3.7:1、ダークで7.3:1。ライトの `muted` を14px未満の常用に使わないでください。

## 文字

2書体だけ。Zen Kaku Gothic New（400/500/700）が全部の文字、Roboto Mono（400/500）が数字。どちらも Google Fonts から読み、系にファイルは持っていません。

段は 10 / 11 / 12 / 13 / 14 / 15 / 16 / 17 / 18 / 20 / 21 / 22px。細かいのは、同じ部品を卓の大きさごとに詰め直しているからです。基準は14px、状態名は22px。10pxは `¥✓` の印だけに使い、それ以下は作りません。

## 余白・角丸・寸法

コードに変数はなく、繰り返し現れた実寸から起こしました。余白は 2 / 4 / 6 / 8 / 12 / 16 / 18px、角丸は 5 / 6 / 8 / 10px とピルの3段。ピルの角丸は常に短辺の半分です（高さ32pxなら16px）。

フロア図の隙間だけは方向で変わります。横向きは行12px・列6px、縦向きは行6px、スマホは4px。行間を列間より広く取るのは、カードが横長だからです。

## 密度

同じ卓カードが4つの姿を持ちます。詳しくは「密度の段」のページへ。

## 使うとき

- 新しい状態を足すなら、色トークンを1つ増やして `--st` に流す。カードにクラスを足さない。
- 警告を足すなら、色と一緒に短い名詞句を用意する。「時間です」「お通し未提供」くらいの長さ。
- 面を重ねるときは 8% / 12% / 45% の3段から選ぶ。新しい比率を作らない。
- 押せるものは `control-lg`（50px）を既定にし、場所がないときだけ `control-md`（36px）、`tap-min`（32px）まで。
- 数字を出すところは `mono` と `tabular-nums` を必ず一緒に。

## 取り込めなかったもの

- フォントファイルは持っていません。Google Fonts 参照のみです。
- ロゴ・アイコンの画像はありません。ヘッダーのアイコンは絵文字の仮置き（`🗑️` `👀` `🧽`）で、コード側に「あとで差し替える」と書かれています。
- React のバンドルは作っていません。プレビューはアプリの `src/App.css` をそのまま読み込んだ静的な再現で、実物のコンポーネントは動いていません。
