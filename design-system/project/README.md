# Minopal デザインシステム

居酒屋のフロアで、片手にお盆を持った人が、歩きながら一瞥で読むための系です。
アプリ `table-check-app` の `apps/web/src/App.css` と React コンポーネントから、実際に使われている値だけを起こしました。

## この系が守っていること

**色は4つの役割だけ。** アイコンのウチワサボテンから4色を取りました。地＝`sand`（暖かい灰色）、操作＝`nopal`（茎の深い緑）、いま対応＝`tuna`（実の朱）、もうすぐ＝`amber`（実の琥珀）。どの色も「何をしてほしいか」を表し、「どの段階か」は表しません。

**段階は文字で出す。** 案内済・お通し済・L.O.済・開始待ち・ファースト済みといった段階ごとの色（以前の青・緑・紫・青緑・ピンク）はやめました。ふだんの卓は無彩色で、段階は状態名の文字で読みます。色が付くのは対応が要る卓だけなので、フロアを一瞥したときに色の付いた卓へまっすぐ目が行きます。

**色だけでは伝えない。** 警告には必ず「お席の時間」「お通し未提供」「L.O.の時間」のような語が付きます。朱と琥珀は色覚シミュレーションで見分けられることを確かめてありますが、それでも語が本体で、色は目を引くための補助です。

**影はない。** 面の区別は 1px と 1.5px の枠と、淡い地（段3）だけで付けます。`shadow` のトークンはこの系には存在しません。

**数字は等幅。** 時刻と経過時間は Roboto Mono の `tabular-nums`。1秒ごとに桁幅が動くと、視界の端で気が散るためです。

**押せるものは指で押せる。** 主要な操作は50px、下限は32px。スマホでは卓カード自体を押して詳細パネルを開き、カードの上に小さなボタンを載せません。

## 色

4色それぞれに OKLCH で作った12段のスケール（`sand-1`〜`sand-12` など）があり、段の意味は全色で同じです。

| 段 | 使いみち |
| --- | --- |
| 1-2 | 地 |
| 3-5 | 部品の面（淡い地） |
| 6-8 | 線 |
| 9-10 | 塗り |
| 11-12 | 文字 |

コードはスケールを直接使わず、役割トークンを通して使います。

| 役割 | ライト | ダーク | 使うところ |
| --- | --- | --- | --- |
| `bg` / `surface` | sand-3 / sand-1 | sand-2 / sand-3 | 画面の地 / カード・パネルの面（ふだんの卓） |
| `text` / `muted` | sand-12 / sand-11 | 同じ段 | 本文・状態名 / 補助・退店済 |
| `line` / `line-strong` | sand-6 / sand-7 | 同じ段 | 罫・枠 / 同じ面に置くボタンの枠 |
| `action` `on-action` `action-text` `action-bg` | nopal-9・白・nopal-9・nopal-3 | nopal-9・白・nopal-11・nopal-3 | 主ボタンの塗り、選んでいるもの、次に出す料理、移動先選び |
| `now` `on-now` `now-text` `now-bg` `now-line` | tuna-9・tuna-12・tuna-11・tuna-3・tuna-7 | tuna-9・sand-1・tuna-11・tuna-3・tuna-7 | いま対応：お通し未提供・お席の時間・オフライン・トイレ等の「時間です」・消去 |
| `soon` `on-soon` `soon-text` `soon-bg` `soon-line` | amber-9・amber-12・amber-11・amber-3・amber-7 | amber-9・sand-1・amber-11・amber-3・amber-7 | もうすぐ：L.O.の時間・送信待ち |

ダークは同じ段の dark 側を使い、地だけ `bg` を sand-2、`surface` を sand-3 に上げます。Web は端末の設定と `data-theme` で切り替わります。iOS はいまライトだけです。

卓カードは、ふだん `surface` の面・`line` の枠・`text` の状態名。L.O.の卓は `alert-soon` で `soon-bg`・`soon-line`・`soon-text`、お通し未提供とお席の時間の卓は `alert-now` で `now-bg`・`now-line`・`now-text` に替わります。退店済みは `exited` で状態名を `muted` に落とすだけです。

### コントラストの実測

文字はどれも、置かれる地に対して 4.5:1 以上です（WCAG 2）。

| 文字 / 地 | ライト | ダーク |
| --- | --- | --- |
| `text` / `bg` | 12.5 | 15.1 |
| `muted` / `bg` | 5.3 | 9.7 |
| `action-text` / `bg` | 7.2 | 10.0 |
| `on-action` / `action` | 8.1 | 5.3 |
| `now-text` / `now-bg` | 5.7 | 8.4 |
| `soon-text` / `soon-bg` | 5.4 | 8.7 |
| `on-now` / `now` | 4.7 | 7.8 |
| `on-soon` / `soon` | 9.2 | 14.1 |

ダークの `nopal-9` は地の上で3.4:1しかないので、文字には段11（`action-text`）を使い、段9は塗りと枠だけにします。

## 文字

2書体だけ。Zen Kaku Gothic New（400/500/700）が全部の文字、Roboto Mono（400/500）が数字。どちらも Google Fonts から読み、系にファイルは持っていません。

段は 10 / 11 / 12 / 13 / 14 / 15 / 16 / 17 / 18 / 20 / 21 / 22px。細かいのは、同じ部品を卓の大きさごとに詰め直しているからです。基準は14px、状態名は22px。10pxは `¥✓` の印だけに使い、それ以下は作りません。

## 余白・角丸・寸法

コードに変数はなく、繰り返し現れた実寸から起こしました。余白は 2 / 4 / 6 / 8 / 12 / 16 / 18px、角丸は 5 / 6 / 8 / 10px とピルの3段。ピルの角丸は常に短辺の半分です（高さ32pxなら16px）。

フロア図の隙間だけは方向で変わります。横向きは行12px・列6px、縦向きは行6px、スマホは4px。行間を列間より広く取るのは、カードが横長だからです。

## 密度

同じ卓カードが4つの姿を持ちます。詳しくは「密度の段」のページへ。

## 使うとき

- 新しい段階を足しても色は増やさない。段階は文字で出し、ふだんの卓は無彩色のまま。
- 警告を足すなら、いま対応（`now`）かもうすぐ（`soon`）のどちらかに入れ、短い名詞句を用意する。「時間です」「お通し未提供」くらいの長さ。
- 押す・選ぶ・移動先を示すものは操作の `action`（茎の緑）。それ以外に緑を使わない。
- 色はスケールを直接使わず役割トークンを通す。文字は置く地に対して 4.5:1 以上を守る。
- 押せるものは `control-lg`（50px）を既定にし、場所がないときだけ `control-md`（36px）、`tap-min`（32px）まで。
- 数字を出すところは `mono` と `tabular-nums` を必ず一緒に。

## 取り込めなかったもの

- フォントファイルは持っていません。Google Fonts 参照のみです。
- ロゴ・アイコンの画像はありません。ヘッダーのアイコンは絵文字の仮置き（`🗑️` `👀` `🧽`）で、コード側に「あとで差し替える」と書かれています。
- React のバンドルは作っていません。プレビューはアプリの `apps/web/src/App.css` をそのまま読み込んだ静的な再現で、実物のコンポーネントは動いていません。
