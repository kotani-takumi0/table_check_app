# 密度の段

卓カードは1つの部品ですが、置かれる場所によって4つの姿になります。クラスは `card` に足す修飾子で、どれも中身の要素は同じです。減らしているのは情報ではなく、配置と文字の大きさだけ。

## 姿

**大きい卓**（`.table.full`）。高さ2行・幅3列のテーブル卓。真ん中に文字盤（大きさは `min(100cqw, 100cqh - 76px)`）、四隅に卓番・人数とコース・段階か理由の札・残り時間。フロアで一番遠くから読む姿です。

**低い卓**（`.table.low`）。上段の高さ1行のテーブル卓。左に卓番・人数・段階・残り時間、右にカードの高さに合わせた文字盤。右上の情報は1行に収まるよう「3/8」「¥✓」と短くします。

**細い卓**（`.table.low.narrow`）。縦向き画面の幅1列の卓。上に情報、下に文字盤。

**カウンター**（`.counter`）。円の文字盤。卓番は円の上、段階は円の下。縦向きはマスが横長で低いので、卓番を円の左に置きます。

**mini**（`.card.mini`）。スマホ。卓番・段階・時:分の3つだけを中央に縦積みし、文字盤は出しません。警告は淡い地の色だけ。操作はカードを押して開く詳細パネルで行います。

## mini の文字は幅で決まる

`.card.mini` は `container-type: inline-size` を持ち、状態とタイマーを `min(12px, 25cqw)` で出します。1列ぶんのカードは幅が48px前後しかなく、タイマーは最大5文字（`1:58`）、状態は最大4文字。固定寸法では溢れるので、カード幅の25%を上限にしています。テーブル卓だけは `min(14px, 25cqw)` まで上げます。

行の高さは `minmax(44px, 1fr)`。3行が読める下限を先に確保し、画面に入らなければフロア図ごと縦にスクロールさせます。

## 短縮ラベル

幅のない姿では状態名を短くします。`ご案内済み → 案内済`、`お通し提供済み → お通し済`、`L.O.確認済み → L.O.済`、`退店済み → 退店済`。短縮を使うのはカウンター席・スマホ・縦向きの細い卓で、読み上げ用のラベルには常に正式名を渡します。

会計済みの表示も同じ考えで3段あります。大きい卓は右上に「会計済」、低い卓・カウンターは「¥✓」、スマホは卓番の横に `¥✓` だけ。切り替えは詳細パネルで行います。

## 向きで変わるもの

縦向きでは配置図ごと時計回りに90度回します。15列×7行が7列×15行になり、カードの並びも回った位置に置き直します（区切り線は引きません）。カードの姿を変えるのは画面の幅ではなく、割り当てられたマス目の縦横比です。

## どこまで削るか

10pxより小さい文字は作りません。押せるものは32pxより小さくしません。この2つに引っかかったら、要素を小さくするのではなく、その姿からその要素を外して詳細パネルへ送ります。mini がボタンを持たないのはこの判断の結果です。
